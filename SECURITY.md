# Security Policy

## Current status

This repository is a static prototype. It has no backend, authentication, database, payment processing, or real customer messaging. Do not use it to store sensitive information or operate a live business workflow.

## Reporting a vulnerability

Please do not publish secrets, personal data, or exploit details in a public issue. Contact the repository owner privately through GitHub's available contact options and provide a concise description, impact, and safe reproduction steps.

## Secrets and data

- Never commit passwords, API keys, access tokens, private keys, customer data, or real invoices.
- Revoke and rotate any secret accidentally committed.
- Validate and authorize all data on the server before adding production integrations.
